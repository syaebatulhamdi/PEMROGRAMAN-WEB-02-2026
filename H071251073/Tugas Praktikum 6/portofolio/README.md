# Cara menjalankan (Praktikum 6)

1. Buat project baru:
   npm create vite@latest portofolio -- --template react
   cd portofolio
   npm install
2. Pasang Tailwind CSS:
   npm install tailwindcss @tailwindcss/vite
3. Salin isi zip ini ke dalam project (timpa file yang ada):
   - vite.config.js
   - src/ (App.jsx, main.jsx, index.css, components/, assets/gallery/)
   - public/profil.jpg
4. Ganti data & foto dengan milikmu, lalu jalankan:
   npm run dev
   npm run lint
